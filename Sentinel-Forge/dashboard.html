Engineered like a SOC

🔐 Least privilege

The runtime role can only SELECT / INSERT / UPDATE — no DELETE or DDL, so investigation history can't be erased through the app.

🧬 Duplicate-safe

SHA-256 fingerprint + unique constraint: re-importing a file stores nothing. Verified 3,260 → 0 on re-ingest.

🔄 Universal ingest

JSON Lines or CSV; auto-maps other tools' field names and value synonyms onto one common schema.

🕑 Strict UTC time

Every timestamp normalised to UTC; zone-less times rejected, so correlation windows stay correct.

🧾 Parameterised SQL

Values bound as parameters; identifiers quoted; config names validated against a strict pattern.

🎲 Reproducible

Same seed → identical dataset, every run. Deterministic tests, comparable results.

🛟
Defensive & synthetic by design. SentinelForge contains no malware or exploit code and never touches real systems. Example addresses use the reserved RFC 5737 / RFC 2606 ranges; the database binds to localhost only.
